# البيان للتسويق الرقمي — موقع الشركة

موقع صفحة واحدة (Landing Page) لشركة تسويق رقمي في الإمارات، مبني بـ **HTML + CSS + JavaScript** فقط بدون أي مكتبات، ومهيأ لمحركات البحث (SEO).

## الأقسام
1. الواجهة الرئيسية + شريط التنقل (قائمة جوال قابلة للطي)
2. من نحن
3. تحسين محركات البحث SEO (منهجية العمل بأربع خطوات)
4. خدماتنا (6 بطاقات)
5. الأسئلة الشائعة
6. تواصل معنا (نموذج يُرسل عبر واتساب + خريطة جوجل)
7. التذييل (4 أعمدة) + حقوق النشر وحسابات التواصل

## ما تم عمله للـ SEO
- `lang="ar"` و `dir="rtl"` و `hreflang="ar-AE"`
- عنوان ووصف Meta مكتوبان حول الكلمات المفتاحية (شركة تسويق في دبي، سيو الإمارات…)
- رابط Canonical + وسوم الاستهداف الجغرافي لدبي
- Open Graph و Twitter Card مع صورة مشاركة 1200×630
- بيانات منظمة JSON-LD: `LocalBusiness` و `WebSite` و `FAQPage` (تُظهر الأسئلة في نتائج جوجل)
- HTML دلالي: عنوان `h1` واحد، تسلسل عناوين صحيح، `header / nav / main / section / article / footer`
- نص بديل `alt` لكل الصور، وتحميل كسول للصور والخريطة
- أيقونات SVG مدمجة بدلاً من مكتبة خارجية (أسرع تحميلاً)
- `robots.txt` و `sitemap.xml` و `site.webmanifest` وصفحة `404.html`

## قبل النشر — غيّر هذه البيانات
ابحث عنها في `index.html` و `js/main.js` و `robots.txt` و `sitemap.xml`:
| الحالي (مثال) | ضع بدلاً منه |
|---|---|
| `https://www.albayan-marketing.ae/` | دومين الشركة الحقيقي |
| `+971 4 000 0000` / `+971 50 000 0000` | أرقام الهاتف والواتساب |
| `971500000000` في `js/main.js` | رقم واتساب الشركة |
| `info@albayan-marketing.ae` | البريد الإلكتروني |
| العنوان والإحداثيات (الخليج التجاري) | عنوان المكتب الفعلي |
| الأرقام (+250 عميل…) | أرقامكم الحقيقية |
| روابط حسابات التواصل | حسابات الشركة |

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع محتويات هذا المجلد إليه.
2. من **Settings ← Pages** اختر الفرع `main` والمجلد `/ (root)`.
3. بعد النشر سجّل الموقع في **Google Search Console** وأرسل ملف `sitemap.xml`.
4. أنشئ ملف **Google Business Profile** للشركة في دبي لتقوية السيو المحلي.
