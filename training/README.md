# صفحة التدريب (دربنا)

صفحة HTML واحدة فيها شرح وأسئلة واختبارات مع تصحيح فوري ومتابعة للمستوى. المحتوى الحالي: الإنجليزي (من ملف الإكسل).

## الملف الجاهز

`dist/darbna-training.html` — صفحة كاملة لوحدها (المحتوى والكود جواها). تقدر:

- ترفعها على دربنا كـ Material من نوع «صفحة HTML تفاعلية»، أو
- تفتحها مباشرة في المتصفح.

التقدم (المستوى، النقاط، الأخطاء، سجل الاختبارات) بيتحفظ في المتصفح. من صفحة «المتابعة» تقدر تنسخ كود التقدم وتسترجعه على جهاز تاني.

## إيه اللي في الصفحة

- **الشرح**: كل درس متقسم لأجزاء، وكل جزء فيه شرح القاعدة والأمثلة بالنطق (زرار السماعة).
- **التدريب**: أسئلة على كل جزء لوحده، وبطاقات حفظ.
- **الاختبارات**: اختبار على الدرس، على الموضوع، اختبار شامل على كل الإنجليزي، واختبار تحديد مستوى (٣٠ سؤال).
- **أنواع الأسئلة**: المعنى، الترجمة، كمّل الفراغ، التعبير المناسب في سياق، كتابة الجملة، ترتيب الكلمات، صح ولا غلط، استماع، البديل، الصيغة الأصح، صحّح الغلط، أسئلة المقابلات (اختيار الإجابة أو تجاوب بنفسك وتقيّم)، فهم النص، والرد المناسب في الحوار، بالإضافة لأسئلة قواعد مكتوبة يدويًا.
- **المتابعة**: مستوى (A1 → C2) محسوب من إتقانك لكل عنصر، نقاط، أيام متتالية، أكتر حاجات بتغلط فيها، وسجل الاختبارات. الأسئلة بتركز تلقائيًا على الحاجات الضعيفة.

## تعديل المحتوى أو إضافة جديد

```bash
pip install openpyxl
python3 training/build.py
```

- **زيادة في الإنجليزي**: عدّل `source/english.xlsx` (نفس شكل الجداول والعناوين) وشغّل الأمر. لو ضفت شيت جديد، ضيف اسمه في `ENGLISH_TOPICS` جوه `build.py`.
- **أسئلة قواعد وشرح إضافي**: في `data/english.extra.json` (المفتاح هو عنوان الجزء).
- **قسم جديد (Front-end، تسويق، ...)**: اعمل ملف `data/<id>.json` بنفس شكل `data/english.json`:

```json
{
  "id": "frontend",
  "title": "Front-end",
  "mono": "FE",
  "lang": "en",
  "desc": "وصف قصير",
  "labels": { "meaning": "إيه معنى", "say": "إيه المصطلح", "write": "اكتب المصطلح" },
  "topics": [
    { "id": "fe-html", "title": "HTML", "desc": "...", "lessons": [
      { "id": "fe-html-0", "title": "الأساسيات", "heading": "", "intro": [], "sections": [
        { "id": "fe-html-0-0", "title": "Semantic tags", "notes": ["شرح..."], "items": [
          { "id": "fe1", "type": "phrase", "en": "<nav>", "ar": "قائمة التنقل", "note": "...", "example": "..." }
        ], "questions": [
          { "q": "السؤال", "options": ["الصح", "غلط", "غلط"], "answer": 0, "explain": "ليه" }
        ] }
      ] }
    ] }
  ]
}
```

أنواع العناصر: `phrase` (مصطلح ومعناه)، `qa` (سؤال وإجابة: `en` و`answer`)، `correction` (`wrong` و`correct`)، `passage` (نص)، `dialogue` (حوار: `role`). الـ `id` لازم يكون فريد ومايتغيرش عشان التقدم يفضل محفوظ.
