# موقع الوكالة (Front-end فقط)

موقع ثابت (HTML + CSS + JavaScript) بدون أي سيرفر أو قاعدة بيانات أو دفع.
كل طلبات العملاء بتتحول مباشرة على **الواتساب** أو **الإيميل**.

## الصفحات
- `index.html` — الرئيسية (Hero، الخدمات، الأرقام، طريقة الشغل، الأعمال، آراء العملاء، الأسئلة الشائعة)
- `services.html` — كل الخدمات (20 خدمة) مع فلتر حسب القسم
- `about.html` — من نحن
- `contact.html` — نموذج طلب عرض سعر يتبعت على واتساب أو إيميل

## تعديل البيانات (من غير ما تلمس الـ HTML)
| عايز تغيّر | الملف |
|---|---|
| اسم الشركة، رقم الواتساب، الإيميل، العنوان، السوشيال | `assets/js/config.js` |
| الخدمات، الأعمال، آراء العملاء، الأسئلة، الأرقام | `assets/js/data.js` |
| الألوان والخطوط | أول جزء في `assets/css/style.css` (`:root`) |

> رقم الواتساب يتكتب بالصيغة الدولية بدون `+` — مثال مصر: `201001234567`.

## التشغيل محليًا
افتح `index.html` في المتصفح، أو:
```bash
cd agency-site && python3 -m http.server 8000
```

## الرفع
الفولدر ده مستقل تمامًا — ارفع محتواه كما هو على:
- **Hostinger**: ارفع الملفات في `public_html` من File Manager.
- **GitHub Pages / Netlify / Vercel**: انقل الفولدر لريبو لوحده واعمل deploy مباشرة (مفيش build).
